Crear Usuario

  • Seleccione el tipo de identificación legal.
  • Ingrese el número de documento sin puntos ni comas.
  • Escriba el nombre completo del usuario.
  • Registre un teléfono de contacto válido (10 dígitos).
  • Asigne un correo único para su inicio de sesión.
  • Ingrese la dirección de residencia actual.
  • Asigne una clave inicial y defina el rol del usuario en el sistema.
  • Haga clic en 'Crear Usuario' para guardar el registro.
